The Admin Panel provides platform-wide management capabilities for OneTest administrators.

<Note>
The Admin Panel is only visible to users with **platform administrator** privileges. If you don't see the Admin option in the sidebar, contact your organization's administrator.
</Note>

## Accessing the Admin Panel

Click **Admin** in the sidebar navigation to access platform administration features.

## Features

<CardGroup cols={2}>
  <Card title="Access Requests" icon="user-check">
    Review and approve or deny user requests for product access. When users request access to a product, administrators see the request here and can grant or reject it.
  </Card>

  <Card title="Products" icon="boxes-stacked">
    View and manage all products across the platform. Administrators can see every product, its members, and usage statistics.
  </Card>

  <Card title="Audit Logs" icon="clipboard-list">
    View a complete log of all system activity including user actions, configuration changes, and security events. Filter by user, action type, or date range.
  </Card>

  <Card title="Usage & Limits" icon="gauge-high">
    Monitor platform-wide usage statistics and configure usage limits. Set weekly coin budgets, view consumption trends, and manage resource allocation across products.
  </Card>
</CardGroup>

## Access Request Workflow

<Steps>
  <Step title="User Requests Access">
    A user requests access to a product they don't currently have permission to use.
  </Step>

  <Step title="Admin Reviews">
    The request appears in the Admin Panel under **Access Requests** with the user's details and the requested product.
  </Step>

  <Step title="Approve or Deny">
    The administrator reviews the request and either approves (granting access) or denies it.
  </Step>
</Steps>
